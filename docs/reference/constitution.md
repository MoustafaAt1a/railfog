# Architectural Constitution

The canonical architectural doctrine for RailFog is defined in
[`docs/CONSTITUTION.md`](../CONSTITUTION.md).

It establishes **The Boundary Rule**:

- **System boundaries & swappable components**: Object-Oriented Programming
  (OOP) and SOLID principles (`providers/*`).
- **Per-request hot execution paths**: Data-Oriented Design (DOD) with zero
  allocations, flat layouts, and contiguous buffers.
